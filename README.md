# Tamp Cafe - Landing Page

An elegant and beautiful landing page for Tamp Cafe, a fine dining establishment located in the heart of Cebu, Philippines.

## Features

- **Responsive Design**: Fully responsive layout that works beautifully on all devices
- **Elegant UI**: Modern, sophisticated design reflecting the cafe's elegant aesthetic
- **Online Reservations**: Interactive reservation form for customers to book tables
- **Menu Display**: Showcase breakfast, lunch, and dinner menus with tabbed navigation
- **Smooth Animations**: Elegant transitions and scroll animations throughout
- **Location Information**: Display cafe location, hours, and contact information

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action
2. **About Section**: Information about Tamp Cafe and its philosophy
3. **Menu Section**: Interactive menu display for breakfast, lunch, and dinner
4. **Location Section**: Address, hours, and contact details
5. **Reservation Section**: Online booking form for table reservations
6. **Footer**: Additional links and social media information

## Setup

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required - it's ready to use!

## Customization

### Colors
The color scheme can be customized in `styles.css` by modifying the CSS variables:
- `--primary-color`: Main dark color
- `--secondary-color`: Accent gold color
- `--accent-color`: Secondary accent color

### Content
- Update menu items, prices, and descriptions in `index.html`
- Modify contact information, address, and hours in the Location section
- Update reservation form fields as needed

### Images
Replace the placeholder image sections with actual cafe photos:
- Hero background image
- About section image
- Menu item images (optional)
